# Chelis 0.18.11 migration

The unreleased hello-chelis 0.1.11 candidate now consumes Chelis 0.18.11,
Coral 0.7.43, Nautilus 0.7.46, Octant 0.13.1, and C-earchin 0.3.5. Reef, release-workflow, Docker build arguments, CI build arguments and
the Compose image tag name those releases consistently. `chelis-std` remains
compiler-bundled at 0.4.0.

## Migration repairs

All 93 maintained Surf files pass the v0.18-to-v0.19 migration check. The 89
Surf/Deep pairs were regenerated with Chelis 0.18.11, and the four Octant
triples were regenerated with Octant 0.13.1. The Octant spans now use schema
1.2; `normal_pdf` carries the translator's three-argument Nautilus stub.

In addition to the prepared syntax migration, released-stack execution exposed
three compatibility classes:

- rank-increasing `expand` calls became `insert` in both linear-regression
  sites and the scalar-to-rank-1 Coral test helper;
- eleven test modules moved from the removed `Std.Test.assert_eq_int` and
  `assert_eq_string` aliases to the generic `assert_eq` export;
- the macro example now exports the `block` helper that its test imports.

Chelis#1258 is fixed at this pin: both `Frame[N]` resugaring routes and the
complete 93-file migration check pass, so the five-file manual exclusion is
retired. The old chelis#405 scalar-gradient minimal case also builds, but a
narrower whole-package limitation remains when the differentiated scalar
function contains local bindings; that residual is tracked as chelis#2379.

## Validation

- `chelis reef build` completes against the fresh released-artifact registry.
- The fresh Linux x86_64 Docker image downloads and validates all six released
  artifacts, then compiles and executes its C-backend gradient smoke.
- In that image, `chelis test tests/ --jobs auto` passes 105/105 and
  `python3 -m pytest -q tests/` passes 108/108, including all seven C-backend
  compile/run goldens, the Octant triples, and the c-earchin fixtures.
- The negative suite passes 3/3; Deep drift, canonical formatting, lint,
  conformance audit, and pin bump-check are green. Lint retains only the
  pre-existing advisory in `src/capstone/transformerblock.ch`.

The whole-package C build remains intentionally bounded by chelis#2379;
standalone `verify/` programs are the proven compiled subset. A fresh red-team
round and hosted CI on the final pushed head remain separate PR gates.
