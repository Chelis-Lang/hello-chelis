# Parked upstream issue drafts

Ready-to-file `chelis#` drafts with their filing condition. Cite the draft path
at the narrowing site until it is filed and gets a number.

A draft lives here when the narrowing is real and cited in
[`../UPSTREAM_BUGS.md`](../UPSTREAM_BUGS.md), but we have not yet reduced it to
a reproducer an upstream maintainer can run. Each draft states what evidence is
still missing; that is its filing condition.
