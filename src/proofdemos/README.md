# Property-bearing calculations

Read and run the six [contextual proof demos](../../examples/proofdemos/README.md).
These modules contain the commented calculations and their authored properties;
the matching entrypoints under `examples/proofdemos/` print example reports.
The [runtime tests](../../tests/proofdemos/) exercise values and domain rejection,
and the [proof gate](../../tests/test_proof_demos.py) checks the exact obligations.
